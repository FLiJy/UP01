# Система управления автосервисом

## Описание проекта

WPF-приложение для работы автосервиса.

Приложение позволяет пользователям авторизовываться в системе, просматривать информацию, выполнять поиск, сортировку и фильтрацию данных.

Для администратора предусмотрены дополнительные возможности управления данными: добавление, редактирование и удаление записей, а также просмотр статистики и формирование отчетов.


## Используемые технологии

- C#
- WPF
- .NET
- Microsoft SQL Server
- Entity Framework
- ADO.NET Entity Data Model 
- Git
- XAML

## Функциональные возможности

### Авторизация и регистрация

- регистрация новых пользователей;
- авторизация пользователей;
- разграничение прав по ролям;
- хэширование паролей;
- проверка введённых данных;
- защита от многократных неправильных попыток входа с использованием капчи;
- смена пароля.

### Пользователь

Пользователь может:

- просматривать данные;
- выполнять поиск;
- сортировать данные;
- фильтровать данные.

### Администратор

Администратор имеет возможности пользователя и дополнительно может:

- добавлять данные;
- редактировать данные;
- удалять данные;
- просматривать статистику заказов;
- экспортировать данные в отчёты.

### Интерфейс

В приложении реализованы:

- единый словарь ресурсов `Dictionary.xaml`;
- единые стили элементов интерфейса;
- светлая и тёмная темы;
- сохранение выбранной темы;
- логотип приложения;
- всплывающие подсказки;
- проверка вводимых данных;
- подтверждение удаления данных;
- подтверждение выхода из приложения;
- динамические заголовки страниц.

## База данных

В проекте используется Microsoft SQL Server.

Основные таблицы базы данных:

- `clients` — клиенты автосервиса;
- `vehicles` — автомобили клиентов;
- `work_orders` — заказы на ремонт (заказ-наряды);
- `users` — пользователи системы.

Между таблицами настроены первичные и внешние ключи.

Полный скрипт создания базы данных находится в:

```text
db/schema.sql
```

## Работа с базой данных

Подключение базы данных в приложении осуществляется через класс `Core`.

Контекст базы данных используется для выполнения операций просмотра, добавления, редактирования и удаления данных.

## Отчёты

Для администратора предусмотрена возможность формирования отчётов по заказам.

Поддерживаются следующие форматы:

- `.xlsx`;
- `.docx`;
- `.pdf`.
